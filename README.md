# Eol — builds

Official client builds of **Eol** (MOBA + Tower Defense) for Windows and macOS. Download the latest one from
[Releases](https://github.com/numkms/eol-builds/releases/latest).

There is no source code here: this repository only hosts release builds, and the game's built-in updater reads
`latest.json` from the latest release. Every manifest is signed; the game refuses an update whose signature or
checksum does not match.

- **Windows:** unzip `Eol-vX.Y.Z-windows.zip` and run `Eol/Eol.exe`.
- **macOS (Intel + Apple Silicon):** see `README-mac.txt` in the release.

Solo against bots needs no account. Online play needs a free account, created in the game.
